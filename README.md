# Escape Market

Escape Market is a web application for buying, selling, and trading used escape room games. The goal is to make it easier for escape room enthusiasts to find new games to play and give previously played games a new home.

## Features

- Browse available escape room games
- View game details, including language, condition, and price
- Filter and search the game listings
- Explore pages for buying, selling, and trading games

## Tech Stack

**Frontend**
- React
- Vite
- JavaScript
- HTML and CSS

**Backend**
- Node.js
- Express
- PostgreSQL

## Project Status

This project is currently under development. The frontend and initial backend integration are in place, and additional functionality is being developed.

## Running Locally

The frontend and backend are run separately during development. The backend requires a PostgreSQL database and environment variables for the database connection.
